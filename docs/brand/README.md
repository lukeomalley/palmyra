## Final prompt

Use case: logo-brand. Asset type: a finished horizontal logo for the GitHub README of Palmyra, a minimal native Android TV launcher named for Palmyra Peak in the San Juan Mountains. Create one minimal, refined mountain symbol to the left of the exact lowercase word "palmyra". Typography: distinctive contemporary geometric/humanist sans serif, generous but disciplined spacing, double-story a, beautifully balanced custom wordmark, understated alpine design studio feel. The icon is a simple asymmetric mountain ridgeline, one tall angular summit and a smaller shoulder, a clean confident monoline silhouette, not inside a circle or badge. One flat muted alpine green color #587B6F for both icon and lettering, chosen to read on light and dark backgrounds. True transparent background. Wide horizontal lockup, roughly 4:1, tightly composed with comfortable clear margins, centered optically. Crisp, vector-like clean edges, no gradients, no shadow, no texture, no extra text, no tagline, no mockup, no watermark, no landscape photography. Spell the only word exactly p-a-l-m-y-r-a. Produce the final project asset, not a presentation sheet.
