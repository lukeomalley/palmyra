# Palmyra wordmark

`palmyra.png` is a transparent PNG generated with the built-in image generation
tool. It is a README asset and is not included in the Android app.

Generation brief: a minimal horizontal mountain symbol to the left of the exact
lowercase word "palmyra", with a contemporary geometric/humanist sans serif,
generous spacing and a double-story a. One asymmetric peak and a smaller shoulder,
no enclosing badge. Muted alpine green (#587B6F), transparent background, crisp
edges, comfortable margins. No gradients, shadows, texture, tagline or mockup.
